# Markdown Serving Hub

This folder is a dedicated space for documentation about how markdown-based knowledge systems are structured, generated, and deployed.

## Contents

- [[quartz-architecture/overview|Quartz Architecture Overview]]
- [[nextjs-vercel-knowledge-base|Building a Similar Knowledge Base with Next.js + Vercel]]

## Why this exists

When your source of truth is markdown, you want:

- **Simple authoring** (write plain `.md` files)
- **Deterministic builds** (same content in, same static output out)
- **Search and linking that feel wiki-like**
- **Fast deployment** on static hosts/CDNs

Quartz gives you that with a compile pipeline and plugin architecture. The companion Next.js guide shows how to design a similar workflow when you want React-driven flexibility.
